Native POSIX Architecture

A true Unix-like command interpreter written in C11 utilizing real kernel primitives:

  • Process Execution: fork() & execvp() with PATH lookup.
  • Process Control: waitpid() status collection ($? exit codes).
  • Pipelines: Multi-stage pipelines via pipe() & dup2().
  • Redirection: <, >, >>, 2>, 2>> with open() flags.
  • Signals: Foreground process interruption with SIGINT (Ctrl+C).
  • Parent Built-ins: Standalone state-changers (cd, export, exit) execute in parent; pipelines execute in children.

WebAssembly Browser Architecture

An educational simulation compiled to client-side WebAssembly with Emscripten:

  • Shared Parser: Identical tokenizer, quote escaping, and AST parser.
  • Virtual Filesystem: Hierarchical in-memory VFS with sample datasets.
  • In-Memory Pipelines: Byte stream pipelining between virtual commands.
  • Security Boundary: Strict allowlist preventing arbitrary JS eval or host compromise.
  • Zero Backend: Deployed as pure static assets to GitHub Pages.
